# 🛡️ Insurance Data Analysis Dashboard

## 📌 Project Overview
This project focuses on analyzing an Insurance dataset using:
- Power BI
- Power Query

The goal of this project is to identify business insights related to:
- Insurance Premium Analysis
- Claim Performance
- Policy Status Monitoring
- Customer Demographics

The project includes:

✔ Data Cleaning  
✔ Data Transformation  
✔ KPI Analysis  
✔ Interactive Power BI Dashboard  


# 🛠 Tools & Technologies Used

- Power BI
- Power Query
- Excel / CSV Dataset
- Data Visualization
- GitHub


##  Dashboard Development
Created interactive dashboard visuals using:
- KPI Cards
- Bar Charts
- Donut Charts
- Area Charts
- Line Charts
- Slicers
- Tables


# 📈 Business Impact
This dashboard helps businesses:
- Track insurance KPI metrics
- Monitor claim performance
- Analyze customer behavior
- Support data-driven decisions
